# Architecture 

## Block Diagram (current)
[PC UI] -> [USB Protocol] -> [Raspberry Pi Pico W] 
    -> [R-2R] -> [Reconstruction Filter] -> [Variable Gain] -> [Output Buffer] -> [Output sinewave]
    -> [Output Buffer] -> [Output squarewave]
    


## Goals (v1.0)
- PC UI control (USB)
- Variable Gain Sinewave, Squarewave.
- Frequency range: 0Hz-1MHz.
